# Dataset Information

## Loan Default Dataset

This project uses the Loan Default Dataset for financial risk analysis and loan default prediction.

**Dataset Details:**
- Total Records: 255,347
- Total Attributes: 18
- Target Variable: `Default`

The dataset contains borrower information, financial characteristics, and loan-related attributes, including income, credit score, loan amount, interest rate, employment duration, and debt-to-income ratio.

## Dataset Availability

The original dataset is not included in this repository.

To reproduce the analysis, obtain the Loan Default Prediction Dataset from its original source on Kaggle and place the CSV file in the `data` folder.

Expected filename: `Loan_default.csv`.
